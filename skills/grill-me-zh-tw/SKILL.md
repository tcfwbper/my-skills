## Language

Write every question, recommendation, and summary in Traditional Chinese (zh-TW, Taiwan usage), with technical terms kept in English. Keep in English:

- The round format's labels (`Q1`, `Recommended`, `Recommended: none`) and the sweep line `<item>: nothing unclear`, with the item name in English.
- Code identifiers, file paths, commands, flags, config keys, error messages, and log lines.
- Product, library, service, and API names.
- Software terms a Taiwanese engineer writes in English: issue, PR, commit, merge, review, branch, API, schema, migration, cache, race condition, and the like.
- Names from the project's own terminology (its `AGENTS.md`, docs, and code), exactly as the project spells them.

Everything else (explanations, reasoning, options) is Traditional Chinese, in Traditional characters and Taiwan vocabulary (程式, 檔案, 資料, 預設, 設定). Word each question so "對" or "好" accepts your recommended answer. The natural next step is `/to-spec`.
